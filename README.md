## What Is This?

This repository contains everything you need to build a **5-watt Inductive Pulse Charging (IPC) system** — a self-charging energy system that uses high-voltage electromagnetic flyback pulses to charge batteries with a measured Coefficient of Performance (CoP) greater than 1.

**This is real, published, peer-reviewed science.** The system has been validated through the Open Science Framework with results published in the Journal of Electrical and Electronic Engineering.

### How It Works

Two batteries alternate roles — one supplies the circuit while the other receives high-voltage flyback pulses from solenoid coils. An automated battery swapper circuit alternates them on a timer. In closed-loop mode, the system is **self-sustaining** while powering a 5W external load (LED light + USB phone charger).

### What You'll Build

- A **PFGen V5A(R) PCB** with all electronic components
- **3 solenoid coils** that generate the flyback pulses
- A **battery swapper circuit** that automatically alternates batteries
- A complete **closed-loop system** that powers a 5W LED light
