# Scaling Overview — From 5W to 10,000W

## The 5W Foundation

The system you build from this repository proves the fundamental technology works. A CoP > 1 at 5W is the same physics as CoP > 1 at any scale — the principles are identical.

## Scaling Principles

Scaling an IPC system involves systematic increases in:

1. **Coil Configuration** — More coils, higher Ampere-Turns, stronger MMF
2. **Active Devices** — Higher-rated MOSFETs/IGBTs for greater peak voltages
3. **Battery Capacity** — Larger batteries with more plate area for greater interaction cross-section
4. **Multiple Channels** — Parallel switching channels for higher throughput
5. **Capacitive Discharge** — Cap dump circuits for high-current pulse delivery at scale
6. **Current Management** — Maintaining MMF while minimizing supply current remains critical

## Scale-Up Tiers

| Tier | Wattage | Key Changes | Applications |
|------|---------|-------------|-------------|
| Basic | 5W | Single V5A(R) PCB, 3 coils | LED light, USB charger |
| Builder | 50-100W | Larger coils, bigger batteries | Small appliance power, off-grid lighting |
| Professional | 1,000-5,000W | Multiple PCB modules, industrial batteries | Home power backup, workshop power |
| Commercial | 10,000W | Custom engineering, professional installation | Commercial building power, industrial |
