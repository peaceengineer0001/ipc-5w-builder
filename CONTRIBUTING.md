# Contributing to IPC 5W Builder

Thank you for your interest in contributing to the IPC 5W open-source project! This guide will help you get started.

## How to Contribute

### Reporting Issues
- Use GitHub Issues to report bugs, suggest improvements, or ask questions
- Include clear descriptions and, where possible, photos or measurements
- Tag issues appropriately: documentation, safety, build-help, enhancement

### Documentation Improvements
- Fix typos, clarify instructions, or add helpful diagrams
- Share build photos and annotated images
- Translate documentation into other languages

### Build Reports
- Document your build process with photos and notes
- Share your test results (battery voltages, charge times, CoP measurements)
- Report any deviations from the guide that improved performance

### Technical Contributions
- Propose component substitutions with test data
- Share coil winding techniques or jig designs
- Contribute calibration procedures or testing protocols

## Submission Process

1. Fork this repository
2. Create a branch for your contribution
3. Make your changes with clear commit messages
4. Submit a Pull Request with a description of what you changed and why

## Guidelines

- Safety first: Never suggest modifications that compromise safety. All high-voltage work must include appropriate warnings.
- Test before sharing: Component substitutions and modifications should be tested and documented before being proposed.
- Keep it accessible: Write for builders of all experience levels. Use clear language and explain technical terms.
- Respect the science: Contributions should be grounded in measurable, reproducible results.
- No vendor links: Keep content vendor-neutral. List component specifications, not store links.

## Code of Conduct

- Be respectful and constructive in all interactions
- Welcome newcomers and help them learn
- Focus on the engineering and keep discussions technical and productive
- Credit others work appropriately

## Questions?

- Open a GitHub Issue for technical questions
- Visit ipc.engineer for the full interactive learning platform
- Check the Peace Protocols repo for AI-assisted building guidance

Every contribution, no matter how small, helps advance accessible energy technology.
